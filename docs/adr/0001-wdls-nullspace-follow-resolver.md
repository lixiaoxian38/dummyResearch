# 跟随关节解算改用 WDLS + 零空间

原先跟随把笛卡尔 twist 交给 MoveIt Servo 默认雅可比伪逆，再用锁 J4、关节软墙遮丑，对准质量和姿态都像补丁。

现改为独立 **WDLS 解算器**节点：加权阻尼最小二乘 + 同周期零空间关节偏好（偏 J5、抑 J1 空转），主任务仍只保证喷枪瞄准。解算器消费目标总线（板/螺母可切换），经 MoveIt Servo 的 **JointJog** 下发，并取代旧 twist tracker 的命令路径。J4 放开；J6 锁定以做 CDC 静默（相机不随 J6 转）。软限位只作安全边距，不作姿态主策略。HUD 不再提供「只中心 / 中心+J4」操作模式。
