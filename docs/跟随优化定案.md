# 跟随系统优化定案

> 来源：`/grill-with-docs` 会话。术语见根目录 `GLOSSARY.md`，架构决策见 `docs/adr/0001-wdls-nullspace-follow-resolver.md`。

## 一句话

手持标定板做 **跟随**：保证 **喷枪瞄准**（光心对准 + 约 20 cm）；到位后 **保持** 并 **CDC 静默**；运动用独立 **WDLS 解算器**（加权阻尼最小二乘 + 同周期零空间关节偏好），经 MoveIt Servo 的 JointJog 下发；为以后换螺母留好 **目标总线**，本轮不验收螺母 LIVE。

## 定案表

| 项 | 定案 |
|---|---|
| 优化重点 | 运动质量（先治绕圈）+ Hold 期 CDC 减负 |
| 产品成功标准 | **喷枪瞄准**：相机光心在目标上，相机到目标约 20 cm |
| 跟随含义 | 手拿着目标，臂跟着走；到位后 **保持**，目标明显挪开再追 |
| 为何不用弱 Hold 常追 | 本机 USB CDC 易卡/超时，持续微调会加重通信负担 |
| 本轮验收目标 | **标定板**；螺母只做结构，不主验 LIVE |
| 绕圈验收 | 允许极短过渡；须较快进入保持并静住（CDC 静默）；不要求绝对零晃 |
| 姿态 | 用运动学正道，不用软限位/锁轴当主补丁 |
| 算法 | **WDLS + 同周期零空间投影**；关节偏好偏 J5、抑 J1 空转；一体动作，非「对准后再摆」 |
| 主任务 / 二次任务 | 主任务只要喷枪瞄准；关节偏好在同一控制周期的零空间里一起算 |
| 锁轴 | **J4 放开**；**J6 锁定**（相机不随 J6 转，锁是为减 CDC，不是因为夹爪） |
| 结构 | 独立 **WDLS 解算器**节点，吃目标总线；旧 twist tracker 退出命令路径 |
| 下发路径 | 解算器 → Servo **JointJog** → CDC bridge；Hold 后停发 + Quiet |
| HUD | 去掉「只中心 / 中心+J4」开关；默认即 J4 自由、J6 锁 |
| 本轮明确不做 | 软墙当主修姿态；弱 Hold 常追；螺母 LIVE 验收；放开 J6「为了瞄准」 |

## 建议实现顺序（确认后开工）

1. 新建 WDLS 解算器节点骨架（订阅目标总线 + TF，发 JointJog）
2. 接入 Hold / CDC Quiet；开始跟随时走新路径，停发旧 twist
3. 标定板实机调权重，验绕圈与保持
4. 核对螺母仍只经目标总线可切换（不主验 LIVE）
5. 更新 HUD / `track_control` / Tracking Hub 接线与文档
